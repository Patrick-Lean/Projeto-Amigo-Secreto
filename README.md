# Projeto Amigo Secreto

Aplicação simples para organizar um sorteio de amigo secreto diretamente no navegador.

## Sobre o projeto

Neste desafio de lógica de programação da Alura, a estrutura visual da página já havia sido fornecida: HTML, CSS e imagem. A atividade foi identificar o que faltava para a aplicação funcionar e implementar as funcionalidades necessárias em `js/app.js`.

## Funcionalidades

- Adiciona nomes à lista de participantes.
- Impede o cadastro de nomes repetidos.
- Exige pelo menos quatro participantes para realizar o sorteio.
- Embaralha os participantes e exibe as combinações em um ciclo, em que cada pessoa tira a próxima da lista e a última tira a primeira.
- Permite limpar os participantes e o resultado para começar novamente.

## Como executar

1. Baixe ou clone este repositório.
2. Abra o arquivo `index.html` em um navegador.
3. Digite os nomes dos participantes, adicionando um por vez.
4. Clique em **Sortear** para ver o resultado.

Não é necessário instalar dependências nem iniciar um servidor.
